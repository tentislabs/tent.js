# `describeTo` of `project`

Who may read what the app offers to programs.

## Value

A rule. Signed-in callers when left out, a key among them. It holds for `/api/openapi.json`, `/api/docs` and the list of commands. `'anyone'` opens them: a description holds names and types and no row.

## Example

```ts
export const shop = project('shop', {
  describeTo: role('staff'),
})
```
