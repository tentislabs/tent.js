# T4002 random-in-query

A query draws a random value: `random()` or `token()`, in `rows:` and in a `run` alike, or `Math.random()` and the random source of the runtime in its code. A query answers the same for the same data.

## The fix

Draw the value in a change or in an action, and hand it to the query as an input, or store it in a row that the query reads.
