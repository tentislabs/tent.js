# `upper`

Writes a text in capitals, by no language's own rules.

## Example

```ts
const code = upper(input.code)
```

## Returns

`text.toUpperCase()`. Handed a reference it answers its record.

## Errors

`code.T0027`: a value of another kind than the word works with, or a value past the limit `valueSize`.
