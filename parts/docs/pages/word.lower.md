# `lower`

Writes a text in small letters, by no language's own rules, so that both sides of a page agree.

## Example

```ts
const key = lower(input.email)
```

## Returns

`text.toLowerCase()`. Handed a reference it answers its record.

## Errors

`code.T0027`: a value of another kind than the word works with, or a value past the limit `valueSize`.
