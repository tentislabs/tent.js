# T7132 stood-in

In a case that `tent test --declared` made, the code called a service or a model, which every such case stands in for.

## Details

A case made from the declarations reaches nothing outside: every service and every model is stood in by one that refuses with this code, and so is a request of a page to another host and a connection of the app's code to another host by any way the runtime gives, a plain `fetch`, `WebSocket`, `node:http`, `node:http2`, `node:net`, `node:tls` or `node:dgram`, held where its socket connects, and a lookup of a name and a pipe of another program; mail goes to the mailbox, and a run that asks a person is answered no. The case goes on with the refusal, and what the definition does with it is its answer: a definition that lets the refusal out is refused with T7132, which the case keeps, as it keeps any other code.

## The fix

Nothing to mend where the answer is what you mean. A test of what the definition does with a real answer is written by hand, with `app.fake`, beside the cases.
