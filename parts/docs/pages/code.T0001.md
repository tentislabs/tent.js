# T0001 not-found

No definition of that name can be reached. A caller gets it with the status 404.

## Details

A call names a function, and nothing but a query, a change or an action of the description is reached by a name: not a table, not the project, not a name that every object of the runtime has. A function exists for a caller only because a definition exists, so nothing becomes reachable by accident.

## The fix

Call a function of the app by its name. `tent map` lists them.
