# T1013 bad-name

The name of a definition or of a column is not camelCase letters and digits.

## Details

A name starts with a small letter and holds letters and digits alone. The name of a component is the one exception: it starts with a capital letter, since it is written as a tag.

## The fix

Give the definition or the column a name in that form, as `openOrders`.
