# `ceil`

Rounds a number up to a whole number.

## Example

```ts
const pages = ceil(count / 20)
```

## Returns

`Math.ceil(n)`. Handed a reference it answers its record.

## Errors

`code.T0027`: a value of another kind than the word works with, or a value past the limit `valueSize`.
