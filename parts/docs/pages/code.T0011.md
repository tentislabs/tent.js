# T0011 bad-description

A description does not have the shape of the format, or holds a stored form that cannot be carried out.

## Details

What carries a stored body or a stored value out raises it for a form that the description does not have: a statement or a value of an unknown form, a word that a body may not call, a name that is no tool of `step`, a call that names no definition, a form that only a sequence of an agent holds, and an `await` in a value that is worked out alone.

The build reports it on a definition whose body, as it was read, does not have the shape of the format, as one that hands `each` a value in the place of its arrow. The definition is left out of the description.

The engine raises it where it opens a bundle, and the app does not open: for a folder that holds no `description.json`; for a description that is no JSON or states no format of ours; for one of a newer format number than the engine's own, naming both; for a description that holds a field which the format does not list, or one of another type, naming each field; and for a bundle that lacks the code of a definition which the description holds as code. An engine reads every older format number.

## The fix

Build the project again, so that the description is written by the build. A description is not changed by hand. Run a bundle with an engine as new as the build tools that built it.
