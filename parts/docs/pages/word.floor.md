# `floor`

Rounds a number down to a whole number.

## Example

```ts
const whole = floor(total / count)
```

## Returns

`Math.floor(n)`. Handed a reference it answers its record.

## Errors

`code.T0027`: a value of another kind than the word works with, or a value past the limit `valueSize`.
