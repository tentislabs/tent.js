# T2003 table-gone

A table that the data holds is gone from the project, and `removed` of the project does not name it.

## The fix

Name the table in `removed` of the project: it is then kept and no longer used, so going back a version loses nothing. Where the table goes on under a new name, state `was` on the new one.
