# `slice`

A part of a text or of a list, from one place to another. A number below zero counts from the end.

## Example

```ts
const firstTwo = slice(rows, 0, 2)
```

## Returns

`x.slice(from, to)`. Handed a reference it answers its record.

## Errors

`code.T0027`: a value of another kind than the word works with, or a value past the limit `valueSize`.
