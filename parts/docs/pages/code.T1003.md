# T1003 unknown-option

A definition, a type or a part of one states an option that it does not have. The finding names the option and the nearest real one.

## Details

It is found for an option of a word, for an option of a type that the type does not take where it stands, as `unique` on an input or a `default` on a `vector`, and for an option of a kind of worker and of a call of a service. The type checker refuses the same option where the definition is written in TypeScript.

## The fix

Write the option that was meant, or take the unknown one out. The pages `topic.words` and `topic.types` list what each word and each type takes.
