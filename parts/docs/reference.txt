# The reference of Tent.js

Every word with its options, every hook, every tag with its properties, every command with its flags, and every code.
Each line is made from the types and lists of this version, with the first sentence of its page, which `tent docs <name>` prints.

## Words

action(name: string, o: ActionOptions) // A function that reaches outside.
  about?: string // One sentence on what the action is for.
  access: Rule // Who may call the action.

  callerGone?: 'goOn' | 'stop' // What becomes of the work when its caller is gone.

  output?: unknown // The type of the answer.
