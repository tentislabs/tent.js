# `table`

A word of the planted tree, which holds one kind of thing.

## Example

```ts
export const orders = table('orders', { total: number })
```

## Options

| Option | What it does |
|---|---|
| `option.table.tenant` | Keeps a file for each tenant |

## Errors

`code.T0001`, where the name is not found.
