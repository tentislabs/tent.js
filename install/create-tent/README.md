# create-tent

Makes a new project of [Tent.js](https://github.com/tentislabs/tent.js), the full-stack React framework built for AI.

```sh
npm create tent my-app
cd my-app
npx tent dev
```

It runs `tent new my-app` of the newest `tentjs`, which writes the project and installs its `tentjs`. The docs ship inside it: `npx tent docs`.
