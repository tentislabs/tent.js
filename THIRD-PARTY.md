# Borrowed parts

Every borrowed part, its licence and its size. A part stands here, with `package.json` and its lock, before any code uses it.

A package that `package.json` names stands in the first cell of its row under its name on npm, with the exact version of `package.json` beside it. What it brings with it, as `package-lock.json` holds it, stands in the last cell, each package as its name, its version and its licence. `node scripts/borrowed.mjs` holds both files against this one. The lock names the program files of every system, and one system installs its own alone: a size is the size on Windows x64, and a MB is 1,048,576 bytes.
